# App screenshots

`shopping-light.png` and `shopping-dark.png` are unedited native Android
screenshots captured on 2026-11-08 from the Qt 6 application at `fd15a13`, using
the isolated API 36 emulator. The four demonstration entries are disposable;
Coffee is checked. No personal shopping data is shown.

The images show the actual app, including the project background artwork.
See [LICENSING.md](../../LICENSING.md) for the project and third-party terms.

`guide/en/` and `guide/fi/` show QShopper 0.1.0 (Android code 6) on a
disposable API 36 emulator at its native 1080 × 2160 resolution. The
[English guide](../guide.html) and [Finnish guide](../guide-fi.html) draw
gesture marks over the JPEGs in the browser. The
[Play draft](../../store/google-play/README.md) links directly to the clean files.
